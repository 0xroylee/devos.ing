# OpenSpec Handoff Review

Confirm only the current checkpoint:

| Checkpoint | Required evidence |
| --- | --- |
| Propose | `proposal.md`, `specs/`, and `tasks.md` exist |
| Approve | The human approved the proposal scope |
| Handoff | Tickets preserve acceptance criteria and relevant spec paths |
| Delivery | Changed files and fresh verification evidence are recorded |
| Archive | Completed behavior is folded back into project knowledge |

Do not plan implementation before proposal approval or archive before fresh
verification passes.
